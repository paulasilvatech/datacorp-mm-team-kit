# Checklist de Perguntas em Aberto — Estágio 1

> 🗺 **Você está aqui:** [Kit PT-BR](../README.md) → [Estágio 1](README.md) → **mysteries-checklist**

> **HARD GATE:** este checklist preserva a rastreabilidade exigida antes do Estágio 2.
> Uma pergunta permanece aberta até receber validação humana explícita baseada em
> evidência; ela não deve ser transformada em resposta, regra ou requisito pelo agente.

## Para cada pergunta em aberto

- [ ] A pergunta foi registrada sem resposta ou conclusão.
- [ ] A evidência contém `path:linha`.
- [ ] O impacto foi registrado.
- [ ] A hipótese está marcada explicitamente como **não confirmada**.
- [ ] Uma pessoa ou área responsável foi indicada.
- [ ] O status foi registrado.
